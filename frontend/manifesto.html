Protocol

Faceless push.
Accountable signal.

IGNIS separates authorship from contribution quality. A local ephemeral identity signs the work, relays remove identifying metadata, reviewers score the diff blind, and accepted signal can be anchored to Solana.

01 / init

Become Ash

A temporary keypair is generated locally. No account, no OAuth, no permanent handle. The session can prove continuity without exposing who you are.

$ ignis init
> identity: ash_7f3a2b9c
> ttl: 72h
02 / strip

Erase Metadata

Author names, emails, timestamps, host fingerprints, and accidental identity markers are stripped before the submission enters review.

$ ignis strip patch.diff
> metadata: removed
> bundle: sealed
03 / prove

Preserve Signal

Reviewers judge the code without profile context. Accepted work receives a verifiable receipt and can be anchored on Solana devnet.

$ ignis proof
> receipt: valid
> anchor: signed
Features

Built for
disappearing.

IGNIS is a privacy-first contribution layer for builders who want code to speak before identity does.

Ephemeral Identity

Local-only keypairs create signed sessions with expiry. Continuity without public profile context.

Relay Routing

Submission bundles move through relay nodes before landing in blind review queues.

Blind Review

Reviewers see the diff, tests, and context. They do not see username, network, country, or reputation graph.

Verifiable Proof

Accepted contributions receive privacy-preserving receipts with integrity checks and optional Solana anchoring.
